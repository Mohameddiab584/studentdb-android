# قاعدة بيانات الطلاب — نسخة أندرويد

مستودع بناء نسخة الأندرويد (APK) من برنامج قاعدة بيانات الطلاب — نفس كود نسخة ويندوز، بطبقة Capacitor.

- البناء يتم تلقائيًا على GitHub Actions مع كل دفع (push).
- ملف الـ APK الجاهز يُنشر في صفحة Releases (وسم apk-debug) وفي Artifacts.
- لا يحتوي هذا المستودع على أي بيانات طلاب — كود البرنامج فقط.
